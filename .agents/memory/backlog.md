# Backlog — Beta program

**Goal:** bring the branch to **beta quality**. The previous alpha punch-list is superseded; this list is the result of a full adversarial audit (type checker core, LSP surface, formatter, config, stubs, engine) with every finding verified empirically before being recorded.

**Beta bar (acceptance):**
- **Sound on idiomatic R:** no known accepts-then-crashes holes on supported constructs; unsupported constructs may be refused loudly (sound-by-refusal is acceptable) but never silently mistyped.
- **Zero false positives on the ~200 most-used base functions** with `[check] typing = true` on idiomatic call forms.
- **Strict mode usable end-to-end** (discoverable config, per-file toggle, fires on real gaps).
- **Annotation UX complete:** formatting, hover, goto-definition, rename/references, highlighting work in all annotation positions, not just compact refs.
- **No server-killing input** (no `unwrap` panics on protocol-legal messages).
- **Perf budgets gated in CI**, not aspirational.

**Sequencing (user-decided): semantics first.** Semantics changes rewrite fixture expectations project-wide; do Phases 1–2 before the polish phases so fixtures are re-blessed once. The independent track can interleave anytime.

## Phase 1 — Semantics core

Update `typing-reference.md` **first** for each item (contract-first), then implement. Settled design rationale: `decisions.md` §Beta-semantics.

- **Multi-member unions** — **DONE.** Surface + core `A | B | C` everywhere a type may appear; normalization (flat, dedupe, `NULL` last, `Any`/`Unknown` absorb) lives solely in `union_of`; unification = set equality + the one nullable member-wise case; member-wise direction lives in compatibility; `if`/`else` joins branches (unify-or-union, `NULL` joins by pure union), `for`/`[` handle fixed-shape lists via the union element type. Contract: `typing-reference.md` §Union types/compatibility/unification.
- **R variable model: function-scoped mutable slots** — **DONE** (bare-name `<-`/`=` only; `<<-`/`->`/replacement forms are the next two items). Naming resolves every write of a name in a frame to one slot with per-read reaching-write sets (`naming.rs` flow walk, loop fixed point); typecheck keys its environment by slot and joins at control-flow merges via `join_types` (env-undo-log snapshots, loop fixed point capped at 3 passes then widen-to-`Unknown`; function bodies now also isolate via the log instead of cloning the whole environment). Package top level keeps winner semantics; conditional top-level assigns get document slots but stay non-global. Unused rebuilt on the reaching sets under its own `unused` diagnostic code (assignment-site reporting; dead stores between writes now caught; the conditional-update and loop-accumulator false positives are gone) — this also delivered the Phase-3 "unused rebuilt on reaching definitions" core (parameters-lint + `DiagnosticTag::UNNECESSARY` still open there). Operators/`$`/`[[`/`[`/`for` accept union operands member-wise with joined results (the headline `x <- 1L; if (f) x <- "two"; x + 1L` now errors on `integer | character`). Contract: `typing-reference.md` §Value names / §Control-flow joins / §Operators over union operands. Follow-ups noted: goto-definition returns the slot's first write only (all-reaching-writes is a later refinement); flow-sensitive narrowing builds on this model (Phase-1 exit note).
- **`<<-`, `->`, `->>` lowering.** Today they are not lowered at all — the whole expression *including the RHS* vanishes from naming and typecheck (`lower.rs` operator catch-all). `->`/`->>` are mirror assigns; `<<-` walks the lexical chain to the nearest enclosing slot (R semantics).
- **Replacement-form assignment lowering:** `x[i] <- v`, `x[[i]] <- v`, `x$a <- v`, `names(x) <- v`, `attr(x, ...) <- v` currently lower whole-expression `Unsupported` with children unvisited (false unused warnings, invisible reads). Lower as read+write of the base variable; type rules per form (start conservative: write of same shape, `$`/`[[` field update).
- **Coercion policy at parameter positions** (kills the stub false-positive machine):
  - whole-number `double` literals are compatible with `integer` parameters (today only `:` special-cases them; `seq_len(10)`, `substr(x, 1, 3)`, `round(x, 2)` all error);
  - `integer` widens to `double` at parameter positions (today forces numeric params to `Any` corpus-wide);
  - vectorized stubs take `T[]` parameters (scalar→vector coercion already admits scalars; today `character`-typed params falsely reject `toupper(c("a","b"))` — the corpus picked the wrong side).
- **Name-aware signature matching** (CRITICAL soundness): annotation parameters are zipped positionally against formals, names ignored (`typecheck.rs` `flatten_expected_parameter_types`); a by-name call then routes values to wrongly-typed formals — verified accepts-then-crashes. R matches by name; the checker must too. This is a **spec bug** (`typing-reference.md` "match by position") — fix the contract and the impl together.
- **Any/Unknown/inference-variable compatibility violations** (verified, spec-breaking): `c(...)` and `for` hard-reject `Any` (spec: compatible with everything) and cascade errors on `Unknown` (spec: never cascade); `c`/`$`/`[[`/`[`/`for` reject unannotated parameters with `expected integer, found type1` — internal metavariable leaked into user wording. Give these constructs the same tolerate-Unknown/constrain-variable treatment arithmetic already has (structural constraints on inference variables: record-with-field, indexable, atomic-element).
- **Variadic calls to locally-defined `function(x, ...)`** are hard arity errors (inference drops `...`). Bridge: make inference lower a trailing `...` parameter as a rest parameter (preferred over a compat special-case).
- **`m[i, j]` / `x[]`** (matrix/data.frame subsetting): unconditional arity error with call-wording, even when the subject is `Unknown`. Check the Unknown/Any short-circuit *before* arity; message must name indexing, not "this call".
- **Shape erasure on comparison/`/`/`^` results** (verified unsound): `function(x) x > 0L` typed `fn(x: T) -> logical` claims scalar; vector argument yields runtime `logical[]`. Result shape must depend on the operand's resolved shape (tie result shape to the constrained variable), or the scheme must not promise scalar.
- **Recursion**: a self-referential binding silently infers `Unknown` return and is *not* a strict origin — every recursive function defeats inference and strict silently. Minimum: make it a strict origin + document; better: fixed-point inference for direct self-recursion with annotated fallback.
- **Order-dependent acceptance**: a successful `check_compatibility` commits unification of directional checks, so `{k(x); h(x)}` passes where `{h(x); k(x)}` errors. Probe-then-rollback for coercion-flavored checks; commit only equalities.
- Smaller verified spec/impl bugs to sweep in the same pass: comparison of two flexible operands imposes no constraint (lists comparable); `$` accepted on atomic named vectors (runtime error; spec bug — `$` ≡ `[["name"]]` is defined unconditionally); `:` accepts vector endpoints through a polymorphic call (numeric constraint lacks scalar-ness); integer-vector arithmetic pins a flexible operand to `double` and then rejects integer callers; positional `[[` on `list[named: T]` rejected (R allows; map-like *vectors* accept — inconsistent); hardcoded `Pair` arity check in the parser hijacks user `Pair` (`type_syntax.rs` literal match); generic application `T<...>` inside a definition ignores parameter shadowing when arguments are present; `Any[]` silently means `list[Any]`; `check_compatibility` variable arms swallow `RecursionLimitExceeded` into plain `false`.

- **Union follow-ups (from adversarial review):** (a) the type grammar has no parenthesized groups, so a union with a function member — `(fn() -> integer) | NULL`, the idiomatic optional callback — is renderable but not *writable*; add paren grouping to `type_syntax`. (b) Compatibility's bind-variable-to-union fast path widens the known order-dependent-acceptance class: `{ g(x); h(x) }` vs `{ h(x); g(x) }` can differ when `g` expects a union and `h` a member (spec-permitted; revisit with member re-probe on later narrowing use).

## Phase 2 — Stub unlock + real corpus

- **`T[]` constrained generics:** generalize `CoreType::Vector`/`NamedVector` to hold an element *type* + a new atomic-element constraint kind (same mechanism as the numeric constraint). Unlocks `rev`/`sort`/`head`/`tail`/`unique`/`abs`/`sqrt` and the whole vectorized-string family with shape preservation. (Settled: constraint mechanism, not traits — `decisions.md`.)
- **Overload sets:** multiple ordered schemes per stub name; call site tries schemes in declaration order with probe-then-rollback, first compatible match wins; all-fail = one diagnostic listing candidates. Stub-surface only at first (`.Rtypes` grammar already permits repeated declarations). Unlocks `min`/`max`/`sum` (type-preserving, currently WRONG as `-> double`), `is`, `extends`, `grep(value=)`, `cor` (vector vs matrix).
- **`@type` declarations in `.Rtypes`:** nominal opaque types in stubs (`data.frame`, `connection`, `factor`, `formula`, `Date`, `environment` as opaque nominals). Unlocks honest `read.csv`/`lm`/`file` signatures; today the format *cannot* say "returns a data.frame" so even project overrides are capped at `Any`. Requires harvesting stubs against a type-definition environment (today an empty one — any stub referencing a named type silently drops).
- **Stub loading must not swallow errors** (`stdlib.rs`: parse errors discarded, harvest failures `continue`, unreadable override files skipped). A typo'd project-override line silently vanishes. Surface as diagnostics.
- **Real corpus (top ~300):** `print`, `stop`, `warning`, `message`, `library`, `require`, `names`, `class`, `inherits`, `structure`, `attr`, `dim`/`nrow`/`ncol`, `which`, `any`/`all`, `unlist`, `match`, `%in%` (needs Phase-1 operator), `identical`, `exists`, `invisible`, `identity`, `do.call`, `match.arg`, `stopifnot`, `tryCatch`, `on.exit`, `switch`, `ifelse`, `seq`/`rep`, `apply` family, file ops (`file.path`, `readLines`, `readRDS`, …), `Sys.*`, full `is.*`/`as.*` families, graphics/grDevices basics (`plot`, `hist`, `png`, `dev.off`). Many are expressible **today** and missing out of pure negligence (`any`/`all` are shape-identical to stubbed `sum`).
- **Fix verified-WRONG stubs:** `sum`/`min`/`max` return types; `paste`/`paste0` reject `collapse=`/`sep=` (named args never route into `...` — add them as optional named); `sprintf` positional-hack forbids `fmt=` by name; `quantile` missing `probs`; `rnorm`/`runif` missing `[mean]`/`[sd]`; `substring` missing `last`; `cor`/`weighted.mean` mandatory optional args; `Reduce` missing `init`; `lapply`/`Filter`/`Reduce` reject atomic vectors (accept `T[]` too); `help` return; `is.na` elementwise claim.
- **Exhaustiveness gauge must stop being self-referential:** `tests/stdlib_exports/*.txt` are hand-built around the corpus and omit `print` et al. Snapshot the *real* export lists (generated once from R, checked in) and report true coverage percentages.
- **Fixture honesty:** stdlib fixtures dodge the coercion problem by writing `1L` literals exclusively; after the Phase-1 coercion change, add idiomatic-call fixtures (`seq_len(10)`, `toupper(c(...))`, `paste(x, collapse=", ")`) so regressions are impossible.
- **`pkg::name`:** real `NamespaceGet` HIR node (today the operator is silently `Unknown` — not even a warning) + namespace-partitioned `StubLibrary`. Without it, package-grade code (the 300k-LoC target) bypasses the entire corpus.
- **`...`-forwarding in higher-order signatures:** `lapply(x, gsub, pattern = "a", replacement = "b")` errors today (callback compat can't absorb forwarded args). Needs a rest-parameter-aware function-compat rule.

## Phase 3 — Trust & UX (config, strict, lints, CLI)

- **Config subsystem rebuild** — core landed: the workspace root comes from `InitializeParams` (`workspace_folders`, then `root_uri`, cwd only when the client sends neither; the worker is constructed by the `Job::Initialize` handler so nothing reads config before the root is known); discovery is one nearest-ancestor search (`Config::discover`, target absolutized first) shared by the LSP (from the client root) and the CLI (from each target argument); unknown keys and type errors are errors with file + 1-based line:column (`deny_unknown_fields` on `ConfigToml`/`FormatConfig`/`CheckConfig`/`LintConfig`; `ConfigParseError` renders the toml span) — the server never panics on a malformed config (defaults at startup, previous config on reload, `window/showMessage` both times; the CLI prints the rendered error and exits non-zero); a successful reload refreshes diagnostics (push: republish open documents; pull: `workspace/diagnostic/refresh`; shared `refresh_all_diagnostics`). Still open:
  - Collapse the four parallel config representations (`ConfigToml`/`Config`/engine `Config`/`CheckConfig`+`LintConfig`) — adding a key currently requires touching ~6 places and missing one is silent.
  - `workspace/didChangeConfiguration` is a no-op stub; editor-settings configuration is silently discarded — either support or reject loudly.
  - Config errors should additionally surface as diagnostics on `roughly.toml` itself (the decision record asks for both; only the window message exists).
  - Reload path compares the watched path to `<root>/roughly.toml` by exact `PathBuf` equality — a symlinked root or case-normalizing client misses the reload (`server.rs`, reload arm).
  - A governing *ancestor* config (above the workspace root) is honored by discovery but not watched — edits to it need a server restart; watch the discovered config's actual path instead of assuming `<root>/roughly.toml`.
  - `Config::discover`'s absolutize failure renders as "failed to read config file `<target>`" where `<target>` is the checked file, not a config file — misleading wording.
- **Strict mode (settled semantics, `decisions.md`):** strict = Unknown origins **and unresolved-name references are errors**; explicit `Any` stays the escape hatch; recursion-Unknown becomes an origin. **Per-file toggle:** top-of-file `#: @strict` / `#: @strict off` directive overriding config (gates are already per-file in both pipelines; derive from the parse so incrementality holds).
- **Unused rebuilt on reaching definitions** (falls out of the Phase-1 slot model): a write no read reaches = unused. Report **assignments**, not bindings. Add: unused function **parameters** (default off or hint-level), unused `library()`/`require()` once imports are modeled. Own diagnostic code (`unused`, not `naming`), `DiagnosticTag::UNNECESSARY` so editors fade it.
- **One lint framework:** `lint.rs` (tree-walk style lints) and the naming-integrated unused check are two disconnected systems. Unify: every lint has a stable code, per-lint severity config, and suppression comments (`# roughly: allow(unused)`-style); duplicated name-style logic collapsed.
- **CLI:** 1-based line:col in rendered diagnostics (currently prints raw 0-based LSP positions, `file:0:11`); don't repeat the message under the caret; `--strict`/severity overrides; `fmt --check`; machine-readable output (JSON) for CI use; exit-code semantics documented.
- **Diagnostic quality sweep:** `type1`-style internal names must never render (map to `T`/`U` or "this value"); wrong-construct wording (`m[1, 2]` reported as "this call passes 2 positional arguments"); `related_information` for defined-here/duplicate pairs; annotation-semantic errors still render under `syntax-error` with doubled `Syntax Error:` prefix.

## Phase 4 — Editor polish (LSP + formatter)

LSP (all verified against code + probes):

- **Server robustness:** `uri.to_file_path().unwrap()` in five notification handlers kills the server on any non-`file:` URI (untitled buffers); range-less (full-text) `didChange` panics — protocol-legal input must not `exit(1)`. Cancelled pull-diagnostics returns an empty **authoritative** report (client caches "no diagnostics") — return ServerCancelled instead.
- **Annotation cursor features, complete:** goto-def/hover work only in *expression-attached* annotations. Dead inside `@type`/`@alias` **definition bodies** (definition blocks never attach to an expression, so `annotation_range_at` never sees them — the most common place for type refs) and inside **generic arguments** (`Wrapper<Person>`: every `<` bumps binder depth, so args classify as `TypeParameter`). References/rename have no type-name path at all — aliases are un-renameable. `@param {T} name` classifies `name` as TypeName (miscolor + wrong-jump). Cursor at a token's right edge misses (end-exclusive containment) — affects plain identifiers too.
- **Completion:** dead while typing after a single `:` (`1:n` — `MaybeNamespace` never resets); **no stdlib completions** (the corpus feeds hover but not completion); no top-level bindings in scripts; `$` completion ignores the type checker (typed record fields are the flagship completion for this product); no type-name completion inside `#:`; items lack detail/documentation/snippets.
- **First code actions** (today: zero, no provider registered): remove unused assignment; prefix with `.`; insert inferred type annotation (inlay-hint machinery already computes the text); `@if-unknown`→`@trust` fix; typo-suggestion for unresolved names.
- Cheap wins with existing machinery: document highlights (references machinery exists); goto-type-definition (checked type → `@type` decl); folding ranges; prepareRename + new-name validation (rename to `my var` currently produces broken R silently); `@type`/`@alias` + `=`/`<<-` bindings in the outline; workspace symbols shouldn't re-walk every package file per keystroke, and should include open scripts.
- **`.Rtypes` served as documents:** diagnostics from the stub parser, semantic tokens, goto-def — stub editing currently has zero tooling.
- **Zed:** Zed does not consume LSP semantic tokens — the `#:` highlighting investment is invisible there; ship tree-sitter injection queries in the Zed extension (and `@`-directive scopes for VS Code TextMate fallback).

Formatter (all verified):

- **Annotation formatter rewrite** (settled design, `decisions.md`): the current per-line ±1 depth walk has **no bracket matching** — the reported `}}` mis-indent and the depth leak poisoning following lines are structural, and the desired output (closers split onto own lines) is unreachable because lines are never split. New shape: join the `#:` block, parse with `type_syntax`'s real parser, pretty-print with per-bracket hug bits (opener followed by content on its line = hugged; closer mirrors its opener) honoring `indent_width`; both the expanded and the hugged style are stable; mixed input normalizes; parse failure → block left verbatim (also fixes prose corruption); drop trailing empty `#:` lines. Kills the drifted duplicate tokenizer (rejects `...` and dotted names like `data.frame`, leaving whole blocks flat).
- **Prose corruption:** `#: value < ten` → `value<ten`; `base::sum` → `base:: sum` — and fixture `double_colon_is_spaced` *blesses* the corruption (violates the never-commit-wrong-expectations rule). Fixed by parse-gating above; fix the fixture.
- **Quarto/knitr `#|` comments corrupted** to `# |` (silently breaks cell options) — add to the comment-prefix exceptions.
- **`# fmt: off` drops leading indentation** (off-mode emits from the node's first byte) and **only works at top level** (toggle lives in the PROGRAM arm only); `# fmt: skip` re-anchors the first line and breaks aligned matrices — the byte-preservation promise.
- ~25 `unreachable!()` arms keyed to grammar shape = process panics on a tree-sitter-r bump; route to the existing `FormatError::UnknownKind` path.
- Empty file becomes `\n` and is reported "reformatted".

- **Formatter follow-ups (from adversarial review):** `# fmt: skip` trailing a non-last call argument is silently ignored (the comma intervenes in the sibling check); `# fmt: off` is inert inside call-argument lists with no diagnostic for the no-op directive; expanded `@param` should support a JSDoc-style trailing description as a first-class parse (parser stores it, checker validates the name, hover can show it, formatter re-emits it verbatim) — today such blocks are simply left verbatim.

## Phase 5 — Perf honesty

- **Single parse per edit:** the engine re-parses from scratch every keystroke (the worker's incrementally-maintained tree is discarded; whole buffer re-materialized as `String` and compared). Feed the edited document/tree into the engine input.
- **Kill the k× multiplier:** `GlobalScheme(s)` runs whole-file inference once *per exported symbol* (finds one export, discards the rest). Add a per-file exported-schemes query. Also: `LoweringDiagnostics(f)` re-lowers the entire file a second time.
- **Template-clone the inference environment:** every inference rebuilds ~19 builtins + ~230 stub schemes from scratch; the oracle already builds once and clones.
- **Gate the budgets in CI:** committed bench shows **72.7 ms/edit at 281 k LoC vs the 30 ms p50 acceptance bar** — currently nothing asserts latency at all. Also benchmark the two unmeasured invalidation cliffs: transient syntax errors (exports flip to empty → cross-file storm every mid-keystroke malformed state) and reference-set edits (SCC re-walks).
- **Memory:** append-only interner, no memo eviction, permanent tombstones, per-`Symbol` keys accrete forever; no post-edit-stream growth test. Bound or evict; add a growth test.
- Deep re-export chains can overflow the fetch spine (recursive `validate`/fetch; only lowering has a depth guard) — process abort on mechanically-generated R.
- **Dedupe the ~600 duplicated lines** between `crates/engine/src/queries.rs` and `analysis` (package-naming diagnostics, surface-type resolvers ×3, strict-origin renderer, SCC fixed-point, unused rendering) — a visibility decision bought a permanent double-maintenance surface; expose the real functions from `analysis` instead.
- Alloc-churn sweep: whole-environment `BTreeMap` clone per function literal; `parameter_variances` recomputed per nominal compat check; per-node `String` in formatter/lint; scope-stack clones per `if`/`for`/`while` in naming.
- `typecheck.rs` structural debt: 7 near-identical `CoreType` recursions (already drifted — two of them drop `RecordField.optional`); byte-identical `infer_builtin_*` bodies; dead `bind_name`/`bind_scheme`/`free_type_variables`; 5.2 k lines in one file — split along environment / unify+compat / operators / calls / annotations seams when touched.
