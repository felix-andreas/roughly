This guide will help you install and set up Roughly for your R projects.

## Installation

### Roughly CLI

<Steps>

1. Download the pre-built binary for your platform from [GitHub Releases](https://github.com/felix-andreas/roughly/releases)
2. Extract the archive and place the binary in your PATH

</Steps>

### VS Code Extension (Recommended)

<Steps>

1. Download the latest `roughly.vsix` from [GitHub Releases](https://github.com/felix-andreas/roughly/releases)
2. Install in VS Code:
   ```bash
   code --install-extension roughly.vsix
   ```
3. Configure in VS Code settings:
   ```json
   {
     "roughly.path": "/path/to/roughly"
   }
   ```

</Steps>

## Command Line Usage

```bash
# Format R files
roughly fmt                # Format current directory
roughly fmt path/to/files  # Format specific path

# Check for issues
roughly check              # Lint current directory

# Run the language server
roughly lsp                # Start the LSP server
```

## Project Configuration

Create a `roughly.toml` in your project root:

```toml
case = "snake_case"  # or "camelCase"
spaces = 2
```

For more information see [here](/configuration).
