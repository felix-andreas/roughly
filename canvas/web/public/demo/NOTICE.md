# Bundled demo project

`R/`, `DESCRIPTION`, and `NAMESPACE` here are the sources of
[stringr](https://stringr.tidyverse.org/), vendored unmodified so the canvas
has a real R package to open on first load. stringr is MIT licensed; its
licence is in `LICENSE`, and copyright remains with its authors.

It is here only as demo input — the canvas analyzes it exactly the way it
analyzes any folder you open yourself. Replace this directory with any other R
package and update `manifest.json` to change the default project.
