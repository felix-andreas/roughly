Roughly — language tooling for R

The rewrite, measured

A greenfield replacement of the analysis stack — hand-written parser on lossless trees, incremental salsa engine, HM type checker — compared honestly against the frozen legacy stack it replaced. The legacy stack stays in-tree as the differential oracle, which is what makes these numbers checkable.

All head-to-head numbers: same machine, same input, one instrument process per measurement. Wall-clock figures swing roughly ±1.4× with machine load; treat ratios as the signal, not the third digit.

Parity is a gate, not a claim

The frozen legacy stack runs inside the test suite as an oracle. Findings are matched by class and range containment — wording is free to improve, behavior is not.

The uncomfortable finding this process surfaced: the rewrite initially shipped with ~30 semantic gaps the legacy stack did not have — script unresolved reads missing entirely, annotations below a statement ignored, unknown type names silently accepted. Property fuzzing never caught them, because nothing asserts a diagnostic should exist. Only the differential did. All are now closed and pinned by fixtures.

The honest ledger

Costs and open edges

  • Both stacks live in the repo. The oracle role keeps ≈34.5K lines of frozen legacy code in-tree (deletion deferred by explicit decision). The parity gates above are the payback.
  • The test suite got heavier. The legacy-corpus arm adds ≈3 min and the per-position IDE arm ≈2 min to every default battery run, in exchange for the guarantees.
  • Some silences are deliberate. |> pipelines, formulas, vectorized &/|, unary +, and S4 @ slots type as tolerantly as legacy did — improving them would shift finding counts and break the gate, so they wait for a renegotiated gate.
  • @if-unknown is parsed but not enforced — a documented gap, not a secret.
  • Parallelism underdelivers (1.2× on 4 workers): the interface fixed point serializes the cold pass. Known lever, not yet pulled.
  • Numbers come from one container. Wall-clock swings ±1.4× with load; authoritative CI perf tracking waits on a workflow file a human must move (token scope).
